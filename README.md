# book-store-database

## Project Overview
This project creates a program for a bookstore to allow the clerk to enter data about new books into the database, update book information, delete books from the database, and search to check the availability of books.
 
## Skills Demonstrated
- Python
- SQL
- SQLite
- Programming
- Error handling

## Features
- Add new books
- Update book and author information
- Delete books
- Search for books
- View complete inventory details
- Relational database using SQLite
- Input validation and error handling
